# Security Policy

## Supported Versions

Only the latest release of `prompt-lint` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability in `prompt-lint`, please report it responsibly:

1. Open a draft security advisory at `https://github.com/YusufBeratZengin/prompt-lint/security/advisories/new`.
2. Provide a detailed summary of the vulnerability, reproduction steps, affected versions, and potential impact.
3. Do not open public issues for security vulnerabilities.

The project maintainer will acknowledge receipt of your report within 48 hours and provide an estimated timeline for remediation.
